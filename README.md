# Baduk Notebook

A personal web app to study, store and annotate Go joseki and shapes (eye shapes, life and death).

- Specification: [SPEC.md](SPEC.md)
- Layout mock-up: [docs/mockup.html](docs/mockup.html) (open it in a browser; sample data only)

Live site: https://jparisu.github.io/baduk-notebook/

## Development

```bash
npm install
npm run dev
```

Databases live in `db/` (see SPEC.md §3). The app is built milestone by milestone (SPEC.md §13).
